# Common tool references for the process checklist

Researched 2026-11-16. This is a proposal, not a runtime registry change. [Structured identities](common-tool-proposals.json) retain the exact model, evidence, retailer status and remaining limits. No prices, location stock, ownership or readiness are inferred. All proposed tool body envelopes remain unknown; blade length, square measuring range, hammer length and clamp opening are not complete three-dimensional tool geometry.

The first five identities cover four missing functions: measuring, squaring, temporary clamping and driving common nails. The two square packages are separate products. One additional hearing-protection reference has positive manufacturer documentation. These tools remain separate from construction materials, fasteners and the material purchase bill.

## Hearing protection option

**3M90565-4DC-PS**, 3M ID7100107419, UPC00076308873356, is a proposed `ppe-hearing` reference. The [manufacturer page](https://www.3mcanada.ca/3M/en_CA/p/d/v000271977/) explicitly states **one earmuff per retail pack, four packs per case**. [HD301277013](https://www.homedepot.com/p/3M-Pro-Grade-Earmuff-90565-4DC-PS/301277013) has the matching model. An exact Lowe’s reference was not verified. The model suffix is not evidence of four earmuffs in one retail unit.

The manufacturer’s [retailer-hosted product sheet](https://images.thdstatic.com/catalog/pdfImages/ca/ca8fa917-ec2b-4a14-b903-9dffccddb39c.pdf) gives the stated30 dB NRR and explicitly discusses fit variation and fit testing. Preserve that scope in tool evidence: this is a hearing-protector function, not a measured personal attenuation value or proof that a particular noise exposure is adequately controlled. Do not subtract the NRR directly from an invented operation-noise number.

Eye and respiratory products were not promoted from incomplete leads. A valid follow-up needs the exact retailer package, manufacturer instructions, hazards/fit and appropriate protection selection. The existing checklist should keep those functions unknown until such evidence and a user selection exist.

## Implementation when the runtime freeze ends

1. Extend the registry capability enum to the narrow functions above. Keep `profile.stockSize:null`, tool category, and tools excluded from material geometry/BOM/support.
2. Add author-reviewed capability evidence with explicit `sourceRefs`, evidence type and scope. Accept only registered primary sources. The current `selectedToolsForProject` adapter specifically requires a DEWALT `/Instruction_Manual/` URL, so merely adding these products would leave every new hand tool unknown. Replace that vendor-specific assumption with exact registry evidence, retaining dated review, unknown-ID/candidate warnings, and nonfuture user review timestamps.
3. Separate function evidence from physical fit and operation conditions. A checked model means the user reviewed documented functions; it does not establish ownership, condition, quantity, safe setup, blade/bit, workspace access or installed fastener approval. A square cannot satisfy cutting; a hammer cannot automatically satisfy the connector-install checklist.
4. Show only reference-status retailer links as buying references; retain retired references in audit data. Never infer84121 stock from a product page. Use the configured store snapshot for price/stock separately.
5. Test separate Swanson package identities, omitted unverified counterparts, retired Lowe’s tape filtering, clamp pack1, hearing pack1/case4, unknown tool envelopes, exact source-capability scoping and unsupported capabilities remaining unknown. Existing DEWALT saw/drill evidence must keep working.
