# Existing products and the initial scope

Research date: November 15, 2026. Based on published product descriptions; these are not hands-on product audits. No claim is made that nothing similar exists.

| Product                                                                                                                                                                 | Published overlap                                                                                        | Why this project still has a useful direction                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| [The Coop Planner](https://thecoopplanner.com/)                                                                                                                         | 3D coop configuration, material calculations, checks, paid plan packages with cut lists and instructions | Strong overlap for coops; does not establish the requested general-purpose, self-hosted assembly workspace and retailer project synchronization |
| [DIYZIGN](https://diyzign.ai/)                                                                                                                                          | Prompt-based woodworking plans, scaled 3D plans, shopping lists, cut lists and build instructions        | Strong overlap with generated plans; public materials do not establish this exact open-source, piece-manipulation workflow                      |
| [Home Depot Material List Builder AI](https://corporate.homedepot.com/news/company/home-depot-launches-ai-powered-material-lists-help-pros-save-time-building-complete) | Interprets project intent into material lists within Pro Xtra Project Planning                           | Real existing retailer planning tool; the announcement does not describe a physics-like board/cut/fastener assembly editor                      |
| [Home Depot project help](https://www.homedepot.com/c/create-a-project)                                                                                                 | Retailer-native material list creation and project planning                                              | Potential handoff destination; no native interoperable 3D project import was verified                                                           |

The useful differentiator is an **open, self-hosted project model** connecting editable physical parts, dimensioned generators, explicit connections, manual steps, operation history, and material purchasing evidence.

The first version uses user-recorded store inventory snapshots, as selected by the project owner. Live availability and native Home Depot project synchronization remain integrations to qualify rather than features to fake.

A documented third-party data route exists, for example [Unwrangle's Home Depot product data API](https://docs.unwrangle.com/homedepot-product-data-api/). Its documentation includes store/ZIP parameters and store-level fulfillment quantities. That establishes a potential adapter route, not authorization, free access, or evidence that an account is configured. No provider was purchased or called with credentials.
