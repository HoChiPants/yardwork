# Synthetic measured-hinge software demo

[Importable project](synthetic-measured-banquette.yardwork.json) · [guide](synthetic-measured-banquette.md) · [hinge datums and metal cuts](synthetic-measured-banquette-hinges.csv) · [shopping list](synthetic-measured-banquette-shopping.txt).

This optional demo contains invented measurement inputs for testing the software. It is not a manufacturer hole pattern, measurements of purchased hardware, a reviewed installation, a complete banquette, or proof of strength. Only the first of three lids has a selected entered axis; the other lids and the carcass screw plan retain pending decisions. Default projects and build studies do not receive these numbers.
